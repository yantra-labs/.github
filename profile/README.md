# Yantra Labs

Yantra Labs is a small engineering lab for building practical tools around AI automation, DevOps, scraping systems, and LLM experiments.

`Yantra` comes from Sanskrit: an instrument, machine, or tool. The name reflects our focus on useful systems that help developers automate work, operate infrastructure, and explore intelligent software.

## Focus areas

- AI agents and automation workflows
- DevOps and platform engineering tools
- Go and Python utilities
- LLM experiments and integrations
- Scraping, data collection, and monitoring systems
- Developer productivity tooling

## Principles

- Build useful tools first
- Keep systems simple and observable
- Automate repetitive work
- Prefer reproducible workflows
- Prefer clear documentation and trade-off notes
